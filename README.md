# Ship Hull Damage Classification Using Hybrid CNN-SVM
## Overview
This repository contains a bachelor's thesis project on the classification of ship hull plate damage using a hybrid CNN-SVM method with texture and color feature extraction.
## Method
The research workflow consists of:
1. Image pre-processing
2. Texture feature extraction
3. Color feature extraction
4. CNN feature extraction
5. Feature fusion and normalization
6. SVM classification
7. Model evaluation

The dataset is not included due to company data restrictions
